# СКОЛКОВО 2046 — бизнес-бакалавриат

Концепт-сайт бизнес-бакалавриата Московской школы управления СКОЛКОВО, подготовленный командой кейс-чемпионата «СКОЛКОВО 2046». Не является официальным сайтом Школы — актуальная информация о программах на [skolkovo.ru/bachelor-programmes](https://www.skolkovo.ru/bachelor-programmes/).

## Что на сайте

- Интро: счётчик лет 2026 → 2046 с «ударом» года
- Главный экран: интерактивная сфера из частиц над кампусом (наведение соединяет, клик рождает «новое знание», перетаскивание вращает)
- Две программы: «Бизнес-бакалавриат СКОЛКОВО» и «СКОЛКОВО и МФТИ»
- Интерактивная схема содержания программ с переключением
- Преимущества с физикой: частицы можно хватать и бросать
- Путь «Старт карьеры», профиль выпускника
- Сцена эпох СКОЛКОВО 1.0 → 2.0 → 3.0 по скроллу
- «Собери дискуссию», студенты, кампус по времени суток, режимы ИИ, гранты

Адаптирован под мобильные: сокращённые тексты, аккордеоны, облегчённые анимации.

## Структура

```
index.html            готовый сайт, один файл (картинки внутри)
src/index.src.html    исходник страницы с плейсхолдерами %%IMG_name%%
src/img/              иллюстрации и фотографии
src/build.py          сборка index.html из исходника
```

## Как править

1. Меняете `src/index.src.html` (или картинки в `src/img/`)
2. Собираете: `python3 src/build.py`
3. Открываете `index.html` в браузере

Шрифты Raleway и JetBrains Mono подключаются из Google Fonts, для правильного вида нужен интернет.

## Публикация

Сайт статический: можно включить GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), и он откроется по ссылке вида `https://<user>.github.io/<repo>/`.
